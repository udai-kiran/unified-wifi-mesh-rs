# G3 code layer: planted bugs in the Rust, caught by the refinement proof

Generated by `verify/mutants/report.py` from a run of `verify/mutants/run-all.sh` (`mutate.py` has the bugs, `run-mutant.sh` the steps, `verdict.py` the one function that decides). Each bug is planted in a disposable copy of `src/lib.rs` under `/cache`, never in the crate. For each mutant: (1) the copy compiles with `cargo` on nightly-2026-09-17, (2) Charon and Aeneas extract it, (3) the extracted `Types.lean` and `Funs.lean` and the unchanged `Abstraction.lean` elaborate in Lean (otherwise the mutant is invalid and the gate fails), (4) the unchanged `Refinement.lean` is compiled against them; Lean must exit 1, and the audit of `AuditAxioms.lean`, run at the end of that file, must show that the `*_refines` theorem of the expected operation depends on `sorryAx` (it no longer checks), (5) a counter-example script is run on the extracted mutant (`native_decide`) and on the reference implementation (which meets the step spec); the named theorem `counter` says that the two differ. The last column runs the crate's Rust tests on the mutant.
